## InstallBlock 1.0.0

### Initial Release
- **System-Level Install Blocking**: Permanently prevents specified applications from being installed or restored by system updates, stores, or unauthorized actors.
- **Dual Operation Modes**:
  - **Normal Mode**: Standard installation flow using native Android package installer prompts.
  - **Shizuku Mode**: Elevated package manager integration for fast, silent background blocking without manual prompt clutter.
- **Tamper-Resistant Guardrails**: Built-in system protection locks and intentional friction confirmation to prevent accidental unblocking.
- **Offline Catalog**: Built-in curated catalog of 3,000+ popular applications and bloatware packages with instant search and custom package support.
- **Strict Privacy**: Zero tracking, zero telemetry, zero analytics, and isolated local-only image processing.
